# CampusOps — Campus Talent Operations Suite

Public **dummy-data** demo of campus hiring tools designed and built by **Mahi Joshi**.

Live employer systems, employee files, offer letterheads, and Outlook send logs are **not** in this repository.

**Fictional company in the UI:** Meridian Payments  
**Product name:** CampusOps

## Open the demo

1. Clone or download this repo.
2. Open `index.html` in a browser  
   or serve the folder (`npx --yes serve .`) and visit the local URL.

After GitHub Pages is enabled, this README will carry the live URL.

## What recruiters can click

| Module | Page | What you are looking at |
|--------|------|-------------------------|
| Hub | [index.html](index.html) | One suite for campus ops |
| Hiring dashboard | [hiring.html](hiring.html) | Funnel, campus quality index, dummy joiners |
| Internship feedback & PPO | [feedback.html](feedback.html) | RM scorecard → HOD decision |

| Bulk Emailer | [emailer.html](emailer.html) | Merge preview (does not send mail) |

## What this is not

- Not production source code from any employer.
- Not real MIS / GET / MT Excel, PPO files, or exit transcripts.
- Offer Maker and Bulk Emailer in real life run on **Windows + Microsoft Word / Excel / Outlook**. Those desktop apps cannot run on GitHub Pages, so this repo explains them and shows a safe specimen.
